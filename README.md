# Video Localization

Video application, domain contracts, conformance, tests, installers, and independent releases.

## Current Status

Repository preparation is local-only. Public source publication is blocked until the exact source-available license and contribution/trademark governance decisions are accepted. No release or support claim is implied.

## First Declared Outcome

Offline CPU media import -> probe -> waveform -> manual cue -> deterministic QC -> SRT/ASS delivery.

The initial supported profile is Windows 11 x64, CPU-only, offline-capable, English and Thai, with System, Light, and Dark appearance modes.

## Repository Rules

- Durable product or Shared artifacts belong in this repository.
- Local planning files under Plan/ are intentionally excluded from Git and must never be uploaded.
- Large media, models, runtimes, codecs, fonts, installers, and generated caches do not belong in Git history.
- Every accepted issue has one type, one priority, at least one area, and a milestone or roadmap:later.
- Public publication, release signing, and remote creation require their recorded governance gates.
