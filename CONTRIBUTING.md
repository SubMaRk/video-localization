# Contributing

External contributions are not accepted while contribution, trademark, modified-build, and official-distribution governance remains pending.

After the governance gate is accepted:

1. Start from a triaged issue with a target milestone.
2. Use a short-lived issue branch.
3. Keep one user outcome per pull request.
4. Add applicable tests, recovery behavior, documentation, and changelog classification.
5. Never include private media, credentials, unapproved dependencies, or Plan/ files.
