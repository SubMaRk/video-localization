# Contributing

This project does not accept external code contributions, pull requests, patches, assets, or documentation changes. DCO and CLA processes therefore do not apply.

## Issues Are Welcome

You may open an issue to report a reproducible bug or propose a feature. Include the affected product, version, environment, expected behavior, actual behavior, and minimal reproduction details. Do not submit private media, credentials, licensed payloads, source patches, or confidential information.

Submitting an issue does not make the reporter a project contributor, transfer ownership, or guarantee implementation. The project owner may independently use the reported facts and ideas when planning the product.

## Owner-Only Changes

Only the project owner may approve pull requests, merge changes, create tags, or publish releases. Internal work must start from a triaged issue, use a short-lived branch, remain within one user outcome, and include applicable tests, recovery behavior, documentation, and changelog classification.

Never commit credentials, private assets, unapproved dependencies, generated caches, or `Plan/` files.
